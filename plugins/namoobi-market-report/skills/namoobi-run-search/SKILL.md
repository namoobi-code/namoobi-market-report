# namoobi-run-search (v1.0)

취미(운동) 탭의 대회 캘린더를 주 1회(월요일) 전면 정밀조사로 최신 유지한다 — 신청 접수 오픈을 놓치지 않는 것이 최우선.
(대회 일정·접수일은 각 대회 공지 텍스트에 있어 자동 파싱이 불가 — 서버 스크래핑은
파싱 품질 문제로 기각(2026-08 실측), 전부 LLM 웹 리서치로 수행한다.)

## 산출물

`data/db/sports_events.json` — 홈피 취미(운동) 탭(리스트+월 달력)이 렌더하는 정본.
**스키마 고정** (프론트 파싱 — 필드 삭제·개명 금지):

```json
{"asof":"YYYY-MM-DD","note":"...","events":[
  {"cat":"카테고리","name":"대회명 연도","date":"YYYY-MM-DD","reg":"접수 요약(사람용 문자열)",
   "place":"장소","url":"공식URL","est":true/false,"regStart":"YYYY-MM-DD(접수 시작일 — 달력 📝뱃지용, 미상이면 생략)"}]}
```

카테고리(고정): 마라톤(세계 8대 메이저)·마라톤(해외 인기)·마라톤(한국)·울트라(한국)·
트레일(한국)·트레일(해외)·철인3종(한국)·하이록스·스파르탄·쉬엄쉬엄3종·기타
※ 8대 메이저 = 도쿄·보스턴·런던·베를린·시카고·뉴욕·시드니·케이프타운(2027 합류)

## 워크플로우

### Phase 0 — 현황 로드

```bash
curl -sk https://141.147.160.13/api/db/sports_events   # 정본 (60건+)
```

### Phase 1 — 정밀조사 (WebSearch · 서브에이전트 병렬 권장)

> ⚠️ 서브에이전트에겐 **조사 보고서만** 요구한다. "파일 수정·서버 업로드 금지"를 프롬프트에
> 명시할 것 — 여러 에이전트가 각자 업로드하면 서로 덮어써 정본이 깨진다(2026-08-10 실측).
> JSON 갱신·업로드는 오케스트레이터가 원본 정본에서 단독으로 수행한다.

1. **신규 대회 탐색**: 카테고리별 웹 검색으로 정본에 없는 메이저급 신규 대회 발굴 —
   한국 마라톤은 풀코스·참가 5천명급 이상 or 유명 대회, 트레일은 UTMB/ITRA/노스페이스급,
   하이록스·스파르탄 신규 개최지. 동네 소규모 대회는 제외. 접수일·공식 URL 확정 후 편입.
2. **기존 추정치(est:true) 확정**: 공식 발표가 나왔는지 검색 → 나왔으면 날짜·접수 확정(est:false).
3. **접수 임박 갱신**: 오늘 기준 30일 내 접수 시작(regStart)인 이벤트의 reg 문자열에 "⚠️" 유지·갱신,
   지난 대회의 ⚠️는 제거.
4. **차기 연도 롤오버**: 대회일이 지난 이벤트는 유지하되(흐림 처리는 프론트가 함),
   차기 연도 대회가 발표됐으면 새 항목으로 추가.
5. **메이저 변동 체크**: 세계 마라톤 메이저 추가/변경(예: 2026-06 케이프타운 8번째 합류),
   UTMB 월드시리즈 한국 대회 신설 여부.

### Phase 1.5 — 고정 확인 리스트 (매회 반드시 점검)

사용자가 직접 지정한 관심 대회. **매 실행마다 아래 전부를 개별 검색해 공식 발표 여부를 확인**하고,
미발표면 est:true + 예상 접수월을 유지한다. 하나라도 빠뜨리지 말 것.

| 대회 | 예상 개최 | 예상 접수 | 주최/비고 |
|---|---|---|---|
| TNF100 코리아 2027 | 2027-05 | **2027-02** | 노스페이스 |
| 동해 스카이레이스 2027 | 2027-05 | **2027-01** | 굿러너컴퍼니 |
| 운탄고도 스카이레이스 2027 | 2027-06 | **2027-01~02** | 굿러너컴퍼니 (2026 실측 2/4~2/9) |
| 쉬엄쉬엄 한강 3종 축제 2027 (제4회) | 2027-06 | **2027-03** | 선착순 3만명 |
| SNTR 성남 트레일 레이스 2027 | 2027-09 | 미상 | 대한트레일러닝협회(ktra.kr) |
| 서울 100K 2027 | 2027-09 (토~일) | **2027-06** | 동마클럽 · 100K=UTMB50K/ITRA2, 50K=UTMB20K/ITRA1 |
| TransJeju by UTMB 2027 | 2027-10 | **2027-03** | UTMB 월드시리즈 |
| 서울마라톤(동아) 2028 | 2028-03 (3월 셋째 일요일) | **2027-06 본접수** | 기록제출은 접수 前 4~5월 |

그 밖의 상시 관심 대회: 강남평화·장수트레일·구석구석·부산브릿지·부산50K·부산바다·
손기정평화·인천마라톤·울주나인피크·IRONMAN 구례/고성·HYROX 서울/인천.

※ 대회일은 **요일 패턴**을 지켜 추정한다(트레일=토요일 출발, 국내 마라톤=일요일,
쉬엄쉬엄=금~일). 요일이 안 맞는 추정 날짜는 잘못된 것이다.

### Phase 2 — 작성 원칙

- reg 문자열엔 접수 방식(추첨/선착순)·시각·마감·유의점(조기마감 등)을 압축.
- 확인 안 되는 날짜는 예년 패턴 + est:true + "(추정)". 지어내기 금지.
- regStart는 달력 📝 뱃지의 원료 — 확정·추정 모두 최대한 채운다.

### Phase 3 — 업로드·검증

```bash
# 키는 ~/.nmr/ 로 복사한다 (/tmp 는 서브에이전트가 남긴 nobody 소유 파일과 충돌 — 2026-08-10 실측)
mkdir -p ~/.nmr && cp <연결폴더>/SECURITY/nmr_deploy_key ~/.nmr/key && chmod 600 ~/.nmr/key
scp -i ~/.nmr/key -o StrictHostKeyChecking=no sports_events.json ubuntu@141.147.160.13:namoobi/data/db/sports_events.json
curl -sk https://141.147.160.13/api/db/sports_events | head -c 200   # 서빙 확인
```

로컬 저장소(namoobi-market-report-server/data/db/)에도 동일 저장.
